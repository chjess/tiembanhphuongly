# Tiệm Bánh Phương Lý — Website

Website bán bánh handmade cho **Tiệm Bánh Phương Lý** — TikTok chính thức: [@lybi1993](https://www.tiktok.com/@lybi1993).

## Chạy local

Mở file `index.html` bằng trình duyệt, hoặc:

```bash
# Python
python -m http.server 8080

# Node
npx serve .
```

Rồi vào `http://localhost:8080`.

## Tính năng

- Landing page hero + bánh 3D CSS
- Menu filter theo danh mục
- Giỏ hàng (localStorage)
- Modal chi tiết sản phẩm
- Form đặt bánh
- Responsive mobile
- Link TikTok

## Tuỳ chỉnh

- Sản phẩm: sửa mảng `PRODUCTS` trong `script.js`
- Màu / font: biến CSS trong `:root` ở `styles.css`
- TikTok: đã gắn `https://www.tiktok.com/@lybi1993`
